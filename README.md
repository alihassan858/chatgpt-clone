# ChatGPT Clone - Static UI

## Objective

The objective of this project is to create a basic ChatGPT-style interface to understand the structure and layout of a chatbot application.

This project is a static and non-functional design focused on UI development.

## What I Built

I created a simple chatbot interface that includes:

- Chat window
- Chat messages
- Text input field
- Send button
- Sidebar
- New Chat button
- Clean and minimal layout
- Responsive design for different screen sizes

## Design Process

First, I created the basic HTML structure for the chatbot interface.

Then, I used CSS to design the sidebar, chat window, messages, input field, and send button.

I also added responsive CSS so that the interface can adjust to smaller screens such as mobile devices.

JavaScript is included only for basic interface behavior. No AI API or backend is connected.

## How It Resembles a Chatbot Interface

The design resembles a chatbot application because it contains a conversation area where user and assistant messages are displayed.

It also includes a text input field and send button similar to a typical chatbot interface.

The sidebar contains previous chat items and a New Chat button to make the interface look like a modern chatbot application.
